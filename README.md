# 🪐 Interactive Solar System Simulator

Hey everyone! 👋

This is a small Python project I built while learning programming. It displays a mini solar system with animated planets and interactive information.

## ✨ Features

- ☀️ Sun at the center with planets orbiting around it
- 🌍 Animated planets with a space-themed background
- 🖱️ Click a planet to view its information
- 📊 Planet details include orbital speed, model distance, diameter, and orbital period
- 🌌 Approximate planet formation age
- 🔗 Clickable Wikipedia link to learn more about each planet
- ⏸️ Pause and resume the animation

## 🛠️ Technologies Used

- Python
- Tkinter
- Math
- Random
- Webbrowser

## ▶️ How to Run

1. Install Python if it is not already installed.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal and run:

   ```bash
   python solar_system.py
   ```

No additional Python packages are required, provided your Python installation includes Tkinter.

## 🎮 How to Use

1. Run the Python file.
2. Click any planet to display its details.
3. Click the Wikipedia link to explore the planet.
4. Use the Pause/Resume button to control the animation.

## 📌 Note

This is a simplified educational simulation. Planet sizes and distances in the animation are not to scale. The displayed orbital speeds are simulation values, while the diameters and orbital periods are approximate real-world values.

## 🙌 What I Learned

While building this project, I practised Python functions, loops, dictionaries, event handling, GUI development, and basic animation.
